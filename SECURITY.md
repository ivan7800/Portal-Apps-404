# Seguridad

## Versiones soportadas

Solo se mantiene la versión publicada más reciente.

## Comunicar una vulnerabilidad

Utiliza la opción privada **Report a vulnerability** del repositorio de GitHub si está habilitada. No publiques secretos, datos personales ni instrucciones de explotación en una incidencia pública.

Incluye el componente afectado, pasos mínimos de reproducción, impacto y una propuesta de mitigación si la tienes. La recepción del informe no implica una fecha concreta de corrección.

## Alcance

El portal es estático, no gestiona cuentas y no recibe datos en un backend. Cada aplicación enlazada es un proyecto independiente y debe auditarse en su propio repositorio.
